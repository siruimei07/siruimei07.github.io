# 酒寄 彩葉 · 月読 RELOAD

Sirui Mei 的个人主页，三渲二（3D 渲染 2D）风格。元素取自 Netflix《超かぐや姫！》——满月、七色发光的「ゲーミング電柱」、竹林与芒草、ツクヨミ的光鱼；画面与界面设计参考 ATLUS《女神异闻录3 Reload》（P3R）：巨大的 PRESS ANY KEY、日期切换动画、水下的主菜单与红白楔形光标、月相 HUD。

线上地址：<https://siruimei07.github.io/>

## 体验流程

1. **NOW LOADING**：月亮由朔到望渐盈，底部是《竹取物语》的开篇句。
2. **标题画面**：坡道尽头是海湾、跨海大桥与对岸的城市，巨大的满月悬在桥上，光鱼群绕月回游；右侧最近的一根电线杆是七色的「游戏电线杆」。左侧是 P3R 式的 `PRESS ANY KEY` 与名字。
3. **按任意键**：整帧画面（连同标题大字）碎成 Voronoi 玻璃片从点击处炸开 → P3 的日期切换：日期沿斜线走到今天，每天配真实的月相，今天落进蓝色斜带并泛起涟漪，显示月名与距满月天数 → 蓝带涨满屏幕、斜切擦除 → 水面从下而上涨满，进入菜单。
4. **主菜单（海的内侧）**：P3R 暂停菜单式布局——左侧白色 `MENU` 竖条与序号、倒悬漂浮的头像（扁平的白/青/藏青/墨四色处理）、倾斜的菜单词、红白楔形光标（楔形内的字变红）、右下角说明与按键提示、钱包框里是近一年提交数。选择不同条目时镜头移到对应的机位，光鱼重新排成该条目的图案（叶、正态分布、`</>`、新月、信封、齿轮）。
5. **子画面**：以光标为中心的波浪墨团（blot）展开进入，返回时圆形收束；
   - `PROFILE`：直立的头像、名牌与 ARCANA「XVIII THE MOON」、简介、GitHub 参数条；
   - `SKILL`：统计 / 经济 / 量化；
   - `WORKS`：P3R 委托列表式的作品与公开仓库（合并 `public/data/github.json`）；
   - `CALENDAR`：月历，每天显示真实月相与提交热度，右侧是当天的月名、月龄、照明比例与距满月天数；
   - `SOCIAL LINK`：以塔罗「月」「魔术师」作为邮件与 GitHub，附「写给月亮的信」；
   - `SYSTEM`：画质（自动 / 高 / 中 / 低）、动效（完整 / 减弱）、帧率显示、返回标题、关于。

右上角 HUD 始终显示今天的日期、星期、时段（P3 的 Morning / After School / Evening…，0–1 点是影时间）与距下一次满月的天数。月相按 Meeus《天文算法》第 49 章计算，满月时刻误差在数分钟内。

## 操作

| 操作 | 效果 |
| --- | --- |
| 任意键 / 点击 / 轻触 | 在标题画面开始 |
| ↑↓（W/S）、滚轮、鼠标悬停 | 菜单中选择 |
| Enter / 空格 / → / 数字 1–6 / 点击 | 打开子画面 |
| Esc / Backspace / 「返回菜单」 | 返回上一层（菜单中按 Esc 回到标题） |
| ↑↓←→、PageUp/PageDown | 子画面内的列表、标签与月历 |

深链接：`#menu`、`#profile`、`#skills`、`#works`、`#calendar`、`#contact`、`#system`；浏览器前进后退可用。系统开启「减少动态效果」时跳过碎裂与日期切换。

## 渲染

自研三渲二管线（`src/engine/`，three.js + WebGL2）：

1. **G-buffer**：4× MSAA、多渲染目标——着色后的 HDR 颜色，以及视空间法线（八面体编码）、视深度与墨线分组。所有表面用同一套 toon 材质：由「月光主光」决定的硬明暗交界、专门设计的阴影色、分段的点光源光斑（七色电线杆、路灯、自动贩卖机）与平涂的大气透视。
2. **墨线**：屏幕空间，按深度跳变（剔除斜面）、法线折角与分组边界描线，远处淡出；同一趟里做屏幕空间边缘光——朝屏幕上月亮的方向采样，落到远处或天空的像素得到亮边。
3. **泛光**：13-tap 下采样 + tent 上采样。
4. **合成**：PBR Neutral 色调映射；标题的 P3R 蓝色双色调；「海的内侧」——亮度分段映射到五级蓝色、按步进时间更新的焦散网与气泡、上亮下暗的渐变，彩色泛光保留为点缀；涨水线、墨团遮罩、菜单头像图层（四色扁平化，部分区域透出背景）都在这一趟完成。
5. **叠加层**：光鱼与彩色碎片在显示空间绘制；标题碎裂时直接绘制碎片。

场景全部程序化：非均匀高度场的山坡、坡道与人行道、四千多栋实例化民居与公寓（窗户由着色器绘制，远处自动取平均）、电线杆与悬链线电线、竹林、芒草、远岸城市（窗灯、电视塔、摩天轮）、带灯索的悬索桥与过桥列车、海面（月光之路、手绘水纹、城市倒影）、长条云与满月（手摆的月海、第谷辐射纹）。

GPU 计时驱动自适应画质（`src/engine/Quality.ts`），渲染像素上限 2560×1440。实测 2560×1440（RTX 5070 Laptop）：标题 ≈ 3.5 ms/帧，菜单与子画面 ≈ 3.3–3.8 ms/帧（p95 < 5.6 ms），远低于 60 帧预算。

## 本地运行

需要 Node.js 22.13+ 与 pnpm（版本见 `package.json` 的 `packageManager`）。

```powershell
pnpm install
pnpm dev
```

完整校验：

```powershell
pnpm run lint
pnpm test
```

调试参数：`?q=ultra|high|medium|low` 锁定画质；`?dbg=1..5` 显示 G-buffer（深度 / 法线 / 墨线分组 / 边缘分量 / 墨线强度）。控制台里 `__app.go("calendar")` 可直接跳转。

## 修改内容

所有文案在 `src/content.ts`：身份、标题、菜单条目（含光鱼图案）、档案、擅长、作品、日历、联络、设置与声明。构建时由 `src/render.ts` 预渲染为静态 HTML——没有 JavaScript 时也是一张完整可读的页面。

## 目录

- `src/app/App.ts`：状态机（加载 → 标题 → 碎裂与日期切换 → 菜单 ⇄ 子画面）、路由、输入、各模式的后期参数、头像图层与光鱼编排。
- `src/engine/`：`Pipeline.ts`（G-buffer / 墨线 / 泛光 / 合成）、`toon.ts`（toon 材质族与共享光照）、GPU 计时、自适应画质。
- `src/world/`：`layout.ts`（场景平面图）、天空与月亮、云、海、地形、民居、街道设施与电线、远岸城市与大桥、芒草与竹林、光鱼 `fish.ts`、碎片 `confetti.ts`、玻璃碎裂 `shards.ts`、`World.ts`（组装与机位）。
- `src/ui/`：加载、HUD、日期切换 `Daybreak.ts`、菜单与光标 `Menu.ts`、各子画面的交互 `screens.ts`、标题文字烘焙 `bake.ts`。
- `src/lib/moon.ts`：月相、月名、距满月天数。

## GitHub 数据与部署

`.github/workflows/pages.yml`：推送到 `main`、手动运行或定时触发 → 同步公开 GitHub 数据 → lint、构建与测试 → 部署 `dist` 到 GitHub Pages。
