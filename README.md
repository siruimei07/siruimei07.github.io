# 酒寄 彩葉 · 月読 RELOAD

Sirui Mei 的个人主页，三渲二（3D 渲染 2D）风格。舞台是 Netflix《超かぐや姫！》的虚拟空间「ツクヨミ」——朱红的月见桥与鸟居、山城的万家灯火、五重塔与灯笼串、成群游过夜空的光鱼、青海波纹的巨鱼飞艇、满月与芒草，以及现实里七色发光的「ゲーミング電柱」；画面与界面设计参考 ATLUS《女神异闻录3 Reload》（P3R）。

线上地址：<https://siruimei07.github.io/>

## 一眼看懂我是谁

- **标题画面**：名字、真名与一句话介绍（多伦多大学本科，统计 · 经济 · 量化）一进来就能看到；「直接进入菜单」可跳过开场。
- **主菜单**：右下角的 PARTY 卡片——彩色头像、名字、学校、方向、GitHub / 邮箱与近一年提交数；菜单词条右侧的说明告诉你每一项里有什么。
- **子画面**：顶部标签栏（`Q` / `E` 或点击）可直接在六个页面间切换，不必回到菜单；每页右下角标出当前场景的地名。

## 体验流程

1. **NOW LOADING**：月亮由朔到望渐盈，底部是《竹取物语》的开篇句。
2. **标题画面 · 月見橋**：站在通往ツクヨミ的朱红长桥上，桥尽头是鸟居与楼门，对岸山城灯火通明，满月悬在城上，光鱼群绕月回游。
3. **按任意键**：整帧画面（连同标题大字）碎成玻璃片炸开 → P3 的日期切换（每天配真实月相，今天落进蓝色斜带；同一次访问再进入时会快进）→ 水面从下而上涨满，进入菜单。
4. **主菜单（海的内侧）**：左侧是一条倾斜的胶片窗——月見ヤチヨ撑着红伞走过八千年（平安、战国、昭和、今日的东京），伞与木屐冲出画框；中间是倾斜的菜单大字与红白楔形光标；背景是**当前选中项自己的场景**，被 P3R 的蓝色水下调色笼罩，移动光标时新场景从光标处以涟漪漫开。
5. **子画面**：以光标为中心的墨团展开，水在其中退去，场景以全彩浮现、镜头推近；返回时两枚圆形收束、海水重新合拢。页面之间切换时是 P3R 式的白蓝斜带扫过。

| 页面 | 场景 | 内容 |
| --- | --- | --- |
| `PROFILE` 档案 | 月読の舞台：山顶神社的舞台，朱柱框住整座ツクヨミ | P3R 头像框里的彩色头像、名牌、简介、资料与 GitHub 参数 |
| `SKILL` 擅长 | 五重塔の路地：仰望五重塔、灯笼串、巨鱼飞艇与光鱼之河 | 统计 / 经济 / 量化 |

| `CALENDAR` 日历 | 月見の野：芒草原与本堂，月亮是**今天真实的月相** | 今夜的月亮、月历、近一年的提交热力图（标出每个满月与连续提交） |
| `SOCIAL LINK` 联络 | 電柱の坂：现实中的坡道，七色的游戏电线杆，电线把一切连在一起 | 邮箱与 GitHub（塔罗「月」「魔术师」）、写给月亮的信 |

| 操作 | 效果 |

## 渲染

自研三渲二管线（`src/engine/`，three.js + WebGL2）：

1. **G-buffer**：4× MSAA、多渲染目标——着色后的 HDR 颜色，以及视空间法线（八面体编码）、视深度与墨线分组。所有表面用同一套 toon 材质：硬明暗交界、专门设计的阴影色、分段的点光源光斑与平涂的大气透视。
2. **墨线 + 边缘光**：屏幕空间，按深度跳变、法线折角与分组边界描线；同一趟里朝屏幕上月亮的方向采样，做出亮边。
3. **特效**：光鱼群、探照灯光束等加法混合的效果在描线之后绘制，自己对 G-buffer 做深度测试。
4. **两个场景交叉时**，各自走完 1–3，再由混合 pass 以涟漪（菜单）或墨迹（切换）过渡。
5. **合成**：PBR Neutral 色调映射；标题的 P3R 蓝色调；「海的内侧」水下调色（亮度分段映射到五级蓝、步进焦散与气泡）、涨水线、墨团退水；八千代的胶片窗（视频上半是画面、下半是伞与木屐出框处的 alpha）。
6. **叠加层**：UI 光鱼图案与彩色碎片在显示空间绘制。

七个场景各自独立、全部程序化建模（`src/scenes/<场景>/`），首屏只加载标题场景，其余在空闲时按需构建并预编译着色器。GPU 计时驱动自适应画质（`src/engine/Quality.ts`），渲染像素上限 2560×1440。

## 本地运行

需要 Node.js 22.13+ 与 pnpm（版本见 `package.json` 的 `packageManager`）。

```powershell
pnpm install
pnpm dev
```

完整校验：

```powershell
pnpm run lint
pnpm test
```

调试参数：`?q=ultra|high|medium|low` 锁定画质；`?dbg=1..5` 显示 G-buffer；控制台里 `__app.go("calendar")` 可直接跳转。
单独查看一个场景：`?scene=bridge|stage|pagoda|avenue|susuki|street|bamboo&shot=title|menu|screen&grade=color|sea|title`（还可加 `cam=x,y,z,yaw,pitch,fov`、`t=秒`、`guides=1`、`hero=1`）。

## 修改内容

所有文案在 `src/content.ts`：身份与一句话介绍、PARTY 卡片、标题、菜单条目、档案、擅长、作品、日历、联络、设置、场景地名与声明。构建时由 `src/render.ts` 预渲染为静态 HTML（含提交热力图）——没有 JavaScript 时也是一张完整可读的页面。

## 目录

- `src/app/App.ts`：状态机（加载 → 标题 → 碎裂与日期切换 → 菜单 ⇄ 子画面 ⇄ 子画面）、路由、输入、场景交叉、八千代胶片窗与光鱼编排；`Viewer.ts`：单场景查看器。
- `src/engine/`：`Pipeline.ts`（G-buffer / 墨线 / 混合 / 泛光 / 合成）、`toon.ts`（toon 材质族）、GPU 计时、自适应画质。
- `src/scenes/`：`host.ts`（场景加载、镜头机位），`common/`（场景接口、光照、镜头、天空与月相、云、光鱼群 `fishStream.ts`），以及七个场景 `bridge` `stage` `pagoda` `avenue` `susuki` `street` `bamboo`。
- `src/fx/`：UI 光鱼图案 `fish.ts`、彩色碎片、玻璃碎裂、八千代胶片 `hero.ts`。
- `src/ui/`：加载、HUD、日期切换、菜单与光标、标签栏、各子画面的交互、标题文字烘焙。
- `src/lib/moon.ts`：月相、月名、距满月天数。

## GitHub 数据与部署

`.github/workflows/pages.yml`：推送到 `main`、手动运行或定时触发 → 同步公开 GitHub 数据（`pnpm sync-data`）→ lint、构建与测试 → 部署 `dist` 到 GitHub Pages。
