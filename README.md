# 酒寄 彩葉 · 月読

Sirui Mei 的 3D 交互个人主页。场景参考 Netflix《超かぐや姫！》中的虚拟空间「ツクヨミ（月読）」：穿越光之隧道，从水中浮出，黄昏的体积云与满湖灯笼，入夜的星轨，水面上唯一的一座鸟居；穿过鸟居的光之水幕，便来到依山而建的月読之都。整体为和风古典：米白明朝体、深蓝夜色、一点朱红，克制的光。

线上地址：<https://siruimei07.github.io/>

## 体验流程

1. **加载**：黑底「月読」，预热全部着色器后出现「启程」。
2. **入场（约 23 秒，可跳过）**——时间轴逐帧对照参考片段 `载入动画.mov`：
   - 0.7–5.4 s 光之隧道：暖色光核与金色尘埃 → 穿过膜环进入暗青色腔室（放射状细纹、流线、气泡、油膜虹彩）→ 玻璃般的水幕涌来、水花炸开 → 光核化为太阳。
   - 5.4–6.5 s 出水：白光中镜头贴着水面、俯视鸟居倒影，随后在水花与湿镜头的竖向光带中抬头，露出黄昏的鸟居。
   - 6.5–11.5 s 黄昏：体积积云（逐个「云塔」组合、Worley 噪声侵蚀出花椰菜状云团，奶油色受光面与鲑粉色阴影）、满湖流灯。
   - 11.5–19.5 s 入夜：太阳沉落、云以延时摄影速度飘移并转为藏青，星星出现并拉成星轨，随后星轨收回成星点。
   - 18.5–24 s 无人机鲸鱼：几千盏「无人机」从湖面网格起飞，拼成一头座头鲸，之后缓慢游过夜空。
3. **封面（序）**：左侧名字与一句话，右侧鸟居与月亮；孔明灯不断升起。
4. **穿过鸟居**（参考 `进入鸟居.mov`）：镜头沿鸟居轴线推进，门洞里出现青色的光之水幕（焦散、下落的光丝、涟漪、闪光粒子），触碰后化作满屏青光与同心圆环，白光之后在月読之都的巨门前醒来：回望巨门与「月読」额、青色光带，再转身面向城市。
5. **月読之都**（参考 `场景1.mov`）：
   - 壱 档案：平台上远眺依山而建的城——町屋的格子窗透出暖光、五重塔、山顶天守、夜樱，月亮悬在山上。
   - 弐 擅长：长桥上空悬着三盏大灯笼「統 · 経 · 量」，悬停卡片时对应的灯笼会亮起。
   - 参 作品：桥头仰望五重塔。
   - 肆 联络：镜头贴着屋顶在街巷间低飞穿城，循环不止；「放飞孔明灯」会让一盏灯升空、放一朵花火。

系统开启「减少动态效果」时跳过入场直接进入封面。

## 交互

| 操作 | 效果 |
| --- | --- |
| 滚动 / ↑↓ / PageUp·PageDown / 空格 / 右侧章节栏 | 在章节间移动（封面 → 穿过鸟居 → 城中各章节） |
| 入场时点击、滚动或按 Esc | 跳过入场 |
| 点击水面 | 涟漪，并从该处升起一盏孔明灯 |
| 点击夜空 | 放一朵花火（菊、柳、环三种，配色为金、朱、樱、银、青） |
| 移动鼠标 | 镜头轻微视差 |
| 悬停「擅长」卡片 | 桥上对应的大灯笼亮起 |

## 渲染与性能

- 自研 HDR 管线（`src/engine/`）：4× MSAA 半精度场景、13-tap 降采样泛光、PBR Neutral 色调映射、显示空间白闪、胶片颗粒与抖动；GPU 计时查询驱动的自适应画质（ultra / high / medium / low，渲染像素上限 2560×1440）。
- 体积云（`src/world/clouds.ts`）：GPU 生成的可平铺 3D Perlin-Worley / Worley 噪声；积云由锚点「云塔」解析场 + Billow 侵蚀组成；棋盘格隔帧光线步进 + 旋转重投影时域累积；法线用云塔的解析梯度 + 噪声梯度（每个采样少了 6 次密度求值）；水面反射使用同一套云的全景图。
- 水面：斜近平面的平面反射、波浪法线把灯光拉成竖直倒影、可叠加的点击涟漪与出水时的翻涌泡沫。
- 星轨是绕天极的实例化弧线带，长度可动画（生长、收回为点），被云遮挡。
- 城市全部程序化：约两千栋实例化町屋（格子窗与障子窗由着色器生成，远处自动取平均避免闪烁）、曲面起翘的歇山式屋顶、五重塔、天守、带灯笼的长桥与平台、按建筑位置烘焙的「灯火地毯」、上万盏街灯与提灯串、点彩式夜樱（每棵树数百个花簇粒子）、光鱼群、孔明灯、无人机鲸鱼、花火——全部在顶点着色器里动画。
- 实测（RTX 5070 Laptop，2560×1440，ultra）：城市章节 GPU ≈ 5 ms/帧；入场与封面 ≈ 6–8 ms/帧（60 帧预算 16.7 ms）。

## 本地运行

需要 Node.js 22.13+ 与 pnpm（版本见 `package.json` 的 `packageManager`）。

```powershell
pnpm install
pnpm dev
```

完整校验：

```powershell
pnpm run lint
pnpm test
```

调试参数：`?q=ultra|high|medium|low` 锁定画质；`?t=9` 冻结在入场第 9 秒（加 `&play` 继续播放）；`?skip=1` 跳过入场。

## 修改内容

所有文案在 `src/content.ts`：ID 与真名、封面标语、各章节、擅长领域（含灯笼上的字）、作品、联络文案。构建时由 `src/render.ts` 预渲染为静态 HTML（无 JS 时也是完整可读的页面）。作品列表会合并 `public/data/github.json` 的星标等数据。

## 目录

- `src/app/`：`App.ts`（加载、入场、封面、穿门、章节状态机、输入）、`Director.ts`（入场时间轴，与参考片段同一时钟）、`ui.ts`。
- `src/engine/`：HDR 管线、GPU 计时、自适应画质、全屏通道与 GLSL 公共库。
- `src/stages/`：`Tunnel.ts` + `tunnelShader.ts`（光之隧道）、`WaterWorld.ts`（水面鸟居）、`CityWorld.ts`（月読之都与镜头站点）。
- `src/world/`：大气与时间（`atmos.ts`）、天空、体积云、水、鸟居、流灯、星轨、出水效果、水花、孔明灯、无人机鲸鱼、花火、光之水幕（`portal.ts`）；`city/` 下是城市布局、建筑、地形、平台与桥、灯火、樱花、光鱼、额与大灯笼。

## GitHub 数据与部署

`.github/workflows/pages.yml`：推送到 `main`、手动运行或定时触发 → 同步公开 GitHub 数据 → lint、构建与测试 → 部署 `dist` 到 GitHub Pages。
